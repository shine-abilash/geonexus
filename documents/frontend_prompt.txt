Build a modern, professional, responsive frontend web application for my project:

PROJECT NAME:
“Space Radiation Prediction & Safe Location Recommendation System”

MAIN PURPOSE:
The system monitors live radiation data from a Heavy Ion Spectrometer, detects real radiation events using a SEPNET model, predicts future radiation using LSTM models, applies physics-based mathematical calculations to estimate radiation exposure/dose, and finally compares nearby locations to recommend the safest location for astronauts.

This is a FRONTEND UI project. Make the interface look like a real aerospace/space-mission monitoring system, not like a generic admin dashboard.

- Clean
- Easy to understand

- Suitable for a college/project presentation
- Responsive

- Dark space-themed interface with blue/cyan accents
- Use cards, glowing indicators, charts, icons and subtle animations
- Do NOT overcrowd the screen

8. RADIATION ANALYSIS PAGE
==================================================

This is VERY IMPORTANT.

Create a beautiful page called:

“RADIATION ANALYSIS”

Subtitle:

“Physics-based calculations convert AI predictions into meaningful radiation exposure.”

Show the mathematical calculations as six sequential cards.

CARD 1:
INTEGRAL FLUX

Formula:
J(>E₀) = ∫ J(E,t) dE

Simple explanation:
“Measures radiation particles above a selected energy level.”

CARD 2:
FLUENCE

Formula:
Φ(E) = ∫ J(E,t) dt

Simple explanation:
“Measures how much radiation passes through an area over time.”

CARD 3:
SPECTRAL INDEX

Formula:
J(E) = J₀ E⁻ᵞ

Simple explanation:
“Shows how radiation intensity changes with particle energy.”

CARD 4:
ENERGY FLUX

Formula:
F(E) = ∫ E J(E,t) dE

Simple explanation:
“Measures how much total energy is carried by the radiation.”

CARD 5:
STOPPING POWER

Formula:
S(E) = −dE/dx

Simple explanation:
“Shows how much energy a particle loses while travelling through material.”

CARD 6:
ABSORBED DOSE

Formula:
D = (1.602 × 10⁻¹⁰) ∫ Φ(E) S(E) dE

Simple explanation:
“Estimates how much radiation energy is absorbed by the astronaut or material.”

Make formulas large and readable.

Do NOT make the formulas look like plain text.
Put them inside beautiful scientific cards.

At the bottom show:

“FINAL EXPOSURE ESTIMATE”

Example:

Risk:
MODERATE
